## Reading the metadata

Every folder event carries `folderId`, the environment slug, and the folder path at the time of the
operation. Paths are recorded as they were before the change, so a rename shows the old location.

## Retention

Folder audit events follow the same retention as the rest of the audit log and are not pruned separately.
